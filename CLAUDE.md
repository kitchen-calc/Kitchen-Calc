# Kitchen Calc — заметки для Claude

- Пользователь пишет по-русски — отвечать по-русски.
- Задания выполнять строго по очереди: не переходить к новому, пока не закончено предыдущее.
- Kitchen Calc Studio (`desktop/`): Electron + three.js, всё в миллиметрах. Каждое слияние в `main` собирает релиз
  `studio-v1.0.N` (установщик и zip «bez-ustanovki»). Веб-версия `/studio` отдаёт только файлы из `STUDIO_TYPES` в `app.py` —
  новый модуль в `desktop/app/` добавлять туда.
- Люди в Studio (галочка «👥 Люди», `desktop/app/people.js`) — **всегда в стиле «Симпсонов»**: жёлтая кожа, большие глаза
  с веками, «морда» (у парня — борода), 4 пальца, плавные формы с чёрным контуром и заливкой в 3 тона. Никаких кубиков
  и угловатых форм «как в Майнкрафте». Двигаются реалистично: подходят, берутся за ручку, тянут, приседают к нижним ящикам.
- Звуки дверей, ящиков и техники (`desktop/app/sounds.js`) играют только в режиме «Люди».
- Калькулятор кухни (`/calc`, `templates/index.html`): «Готовые варианты» — 4 раздела по 2 кухни (`PRESET_CATS`, поле `cat`).
  Картинки карточек — рендеры из самого калькулятора `static/home/kc-<render>[-b][-640].webp`; камеры — в поле `cam` варианта.
  Перерисовать: `node tools/render-presets.mjs [id…]`, затем поднять `KC_REN_V`. Вариант без `cat` в сетке не виден
  (`prestige` — для подписи на фото в шапке).
- Studio «✨ Интерьер» (`desktop/app/objects.js`): электрика, светильники, LED, стеновые панели, декор, стулья, жалюзи — разделы `OBJ_CATS`;
  в проекте это `kind: 'appliance'` с `spec.obj = true`. Лампы светят при выключенном 💡 Свет. Примеры проектов — `desktop/app/samples.js` (кнопка «📂 Примеры»).
